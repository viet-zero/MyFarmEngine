# Thư mục hướng dẫn MyFarmEngine

Đây là chỗ riêng để học cách chạy, sửa và mang các phần của đồ án sang game khác. Mỗi bài ghi công dụng hàm, tham số và các biến có thể chỉnh.

- [WorldMap, chunk, camera và object](WorldMap.md): tự dựng thế giới ba vùng, chỉnh kích thước/terrain/spawn, thêm object.
- [Giai đoạn 2 — OpenGL và hình ảnh](Phase2.md): camera, shader, sprite, atlas và cách build phiên đồ họa đầu.
- [Phase D — sự kiện, hiệu ứng và tương tác](Interaction.md): luồng input → luật chơi → event → effect, chỉnh range/cooldown/stamina/capacity.
- [Phase E — bản đồ, animation và va chạm](CollisionVaDoHoa.md): ảnh liên tục, atlas, collider chân, trượt dọc rào, chỉnh CSV và hàm/thông số.
- [Build, test và chạy](BuildVaChay.md): công cụ, lệnh, file EXE, cách đọc kết quả test.
- [Kế hoạch chơi online](../Docs/KeHoachOnline.md): phòng chơi, đồng bộ, chat chữ và thoại (chưa triển khai).

Tài liệu kiểm toán và lịch sử các phase vẫn nằm trong `Docs/`. Khi một hướng dẫn chi tiết được cập nhật, file ở đây là bản chính.
